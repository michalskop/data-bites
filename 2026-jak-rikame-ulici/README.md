# Jak říkáme ulici? (street-name atlas, six regions)

Gallery of six framed, high-resolution (3372 px wide) street-name maps exported from
`/home/michal/dev/ai/data-at/30days/09` with `scripts/export_frames.py`
(DACH, Spain + Andorra, UK + Ireland, Spanish-speaking Latin America, Arabic world, US + Canada).
Each export contains title, map, legend, street plates and credits at default selections.

Preview: `python3 scripts/preview.py --port 8002` → http://localhost:8002/2026-jak-rikame-ulici/
