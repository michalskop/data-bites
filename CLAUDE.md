# Repository instructions

Read and follow [AGENTS.md](AGENTS.md), especially the mandatory media policy:
upload media through `scripts/upload_media.py` to Backblaze B2, reference the
verified `https://media.datatimes.org/databites-dtcz/` URL, and never commit media to GitHub.

Install the tracked hook with `git config core.hooksPath .githooks` on each clone.
